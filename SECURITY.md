# Security

FocusBae keeps meeting audio, transcripts and notes on your Mac, so a security bug
here can expose private conversations. Please report one privately.

**Report:** open a [private security advisory](https://github.com/Prateek-Vortex/focusbae/security/advisories/new)
on GitHub. Do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, the FocusBae version (Settings →
About) and your macOS version. You will get a reply within 7 days.

**In scope:** anything that sends workspace content off the Mac without the user
turning it on, bypasses Strict Local, reads another app's data, or runs code from
a note, import or attachment.

**Supported versions:** the latest public release.
